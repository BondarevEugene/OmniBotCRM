Как включить для конкретного бота

Откройте «Боты → нужный бот → Настройки → Платежи». Внесите индивидуальный Payee ID / Merchant account / Public key / Merchant ID и включите провайдера. Для бота доступны только его собственные реквизиты и разрешенные общие поля.

После изменения общих значений опубликуйте новую версию настроек каждого затронутого бота, чтобы он получил обновленный снимок через защищенный шлюз. CRM использует актуальные поля для ручной сверки платежей.
