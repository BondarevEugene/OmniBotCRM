# OmniFactory CRM 1.13.2 — реестр ключей OpenAI

## Что добавлено

После ручной или автоматической синхронизации организации страница **Системы → OpenAI · ключи** (`/openai/keys`) показывает все доступные через подключенный Admin API key действующие проектные API keys по каждому проекту и реестр административных ключей. Отображаются ID, имя, владелец, тип владельца, признак доступа владельца к проекту, даты создания, последнего использования и окончания действия, маскированное представление, связь с ботом и сумма USD по ID ключа за 30 дней. Есть поиск, фильтры, 50 строк на страницу и CSV. При частичной синхронизации старый снимок ключа помечен `stale`. CRM читает метаданные и не выполняет выдачу или удаление ключей.

OpenAI не возвращает действующие секретные значения ранее созданных ключей при чтении реестра; их нельзя восстановить из Admin API. CRM хранит зашифрованный Admin API key подключения, а импортированный реестр содержит только ID и безопасные метаданные. Новый секретный ключ можно получить только в момент его создания и отдельно разместить в продукте после решения о порядке выдачи/ротации.

## Обновление в Windows PowerShell

1. Скачайте `OmniFactory_CRM_1_13_2_OpenAI_Key_Registry.zip` в `Downloads` и остановите `launcher.py` через `Ctrl+C`.
2. Откройте PowerShell **в корне существующего проекта** `omnibot_crm`. Выполняйте строки целиком:

```powershell
$ErrorActionPreference = 'Stop'
$archive = Get-ChildItem "$env:USERPROFILE\Downloads" -Filter '*1_13_2*Key*Registry*.zip' -File | Sort-Object LastWriteTime -Descending | Select-Object -First 1
if (-not $archive) { throw 'Архив 1.13.2 не найден в Downloads' }
Expand-Archive -LiteralPath $archive.FullName -DestinationPath '.\_crm_keys_1_13_2' -Force
.\.venv312\Scripts\python.exe .\_crm_keys_1_13_2\apply_update.py --check
.\.venv312\Scripts\python.exe .\_crm_keys_1_13_2\apply_update.py --apply
.\.venv312\Scripts\python.exe .\launcher.py start
```

3. Откройте `/openai/keys`. Нажмите **«Обновить из OpenAI»** (вы вернётесь на экономику), затем снова откройте **OpenAI · ключи**. На первой синхронизации/API-отказе смотрите статус и код ошибки в верхней панели.
4. Убедитесь, что появились проекты, ключи, даты и экспорт CSV. Привязка ключа к Food_Porn выполняется в `/openai` после синхронизации.

Инсталлятор проверяет точную цепочку версии 1.13, создаёт резервную копию изменяемых файлов в `.crm_update_backups/openai_keys_...`; `.env` и база не изменяются. Для отката остановите CRM и верните шесть файлов из созданной папки, а новый `crm/templates/openai_keys.html` удалите. Затем запустите CRM снова. Миграцию Alembic запускать не требуется.

Если статус `partial`, OpenAI не разрешил читать некоторые ресурсы: старые строки реестра помечаются `stale`, если их нельзя было обновить. Реестр не включает отозванные/удалённые ключи, которые API больше не перечисляет; сумма по ключу зависит от группировки Costs API.
